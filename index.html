The Event

Join the eBay Accessibility Team at the eBay office for a workshop on using AI for accessibility tasks. This is going to be a hands-on session, so participants are asked to bring their laptops in order to participate fully. The workshop will cover the basics of using AI agents and skills before participants will work on building their own AI skill for accessible UI development.

To make this workshop as open to everyone as possible, we'll be sticking to free tools and open source resources. We will be using GitHub, Visual Studio Code, and Microsoft Copilot. Prior to the workshop we ask that you have both a GitHub account setup and Visual Studio Code installed on your machine.

Attendee prerequisites:

  • Laptop (if your work laptop has any restrictions on installing software or using AI tools like Copilot, we recommend bringing a personal device)
  • GitHub.com account
  • Download Visual Studio Code

Event Info

  • eBay Toronto, 155 Queens Quay East, Toronto, ON M5A 1B4
  • Floor: 6th floor
  • eBay is located in the Waterfront Innovation Centre near Sugar Beach.
  • Various TTC buses stop nearby
  • Paid parking nearby;
  • Anyone travelling by Uber/Rideshare should use the address 25 Dockside Drive, this leads to the rear door of the building and is a safer drop-off location than directly off Queen’s Quay.

Please note: Attendees must bring government-issued photo ID to enter eBay.

We look forward to seeing you there!
